# attendance_system
2回目模擬案件　勤怠管理

## Dockerビルド
```
- git clone [git@github.com:mayu-ya/attendance-system.git](https://github.com/mayu-ya/attendance-system.git)

- cd attendance-system

-docker-compose up -d --build
```

## Laravel環境構築
```
- php artisan key:generate
```
