# attendance_system
2回目模擬案件　勤怠管理

## Dockerビルド
```
git clone git@github.com:mayu-ya/attendance-system.git

cd attendance-system

docker-compose up -d --build
```
GitHubのURL：https://github.com/mayu-ya/attendance-system.git

## Laravel環境構築
```
docker-compose exec php bash

composer install

cp .env.example .env
```
```
#Your lock file does not contain a compatible set of packages. Please run composer update.とエラーが出たときは以下を実行する。
composer update laravel-lang/lang --no-plugins
```
``` .env
#この箇所を変更
DB_CONNECTION = mysql
DB_HOST = mysql
DB_PORT = 3306
DB_DATABASE = laravel_db
DB_USERNAME = laravel_user
DB_PASSWORD = laravel_pass

#パーミッションエラーで変更できない場合は、コンテナを抜けて以下を実行する
sudo chmod -R 777 src/.env
```
```
php artisan key:generate

php artisan migrate:fresh

php artisan db:seed
```

## テーブル説明
- attendance_records_table  ->勤怠
  - id
  - user_id
  - date
  - start_time  ->出勤時間
  - end_time    ->退勤時間
  - work_total  ->1日の労働時間（休憩時間除く）
  - duration    ->1日の休憩時間合計
  - created_at
  - updated_at

- breaks_table  ->休憩
  - id
  - attendance_record_id
  - rest_start  ->休憩開始時間
  - rest_end    ->休憩終了時間
  - rest_total  ->合計（1回分）
  - created_at
  - updated_at

- applies_table  ->申請承認用
  - id
  - user_id
  - admin_id    ->誰が承認したのか
  - attendance_record_id
  - date
  - start_time  ->出勤時間
  - end_time    ->退勤時間
  - work_total  ->1日の労働時間（休憩時間除く）
  - duration    ->1日の休憩時間合計
  - content     ->備考欄の内容
  - status      ->'pending : 承認待ち','approved : 承認済み'のいずれかを保存
  - created_at
  - updated_at

- rests_table  ->申請承認用
  - id
  - attendance_record_id
  - rest_start  ->休憩開始時間
  - rest_end    ->休憩終了時間
  - rest_total  ->合計（1回分）
  - created_at
  - updated_at

- reports_table  ->月次レポート
  - id
  - user_id
  - month           ->'2026-06'の形で保存する
  - total_work      ->総労働時間/月
  - total_overtime  ->総残業時間/月
  - average_work    ->平均労働時間/月
  - behind_time     ->遅刻回数/月
  - leaving_early   ->早退回数/月
  - overtime_day    ->長時間労働日数/月
  - created_at
  - updated_at

## 留意点
- 画面設計のスタッフ側のヘッダーのnavタグは、「勤怠　勤怠一覧　申請　レポート　ログアウト」と統一している。「今月の勤怠一覧　申請一覧」は不採用にしてある。このことはコーチに確認済みである。
